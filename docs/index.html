What it does

Player

The direct file plays in an ordinary video element — keyboard shortcuts, resume where you left off, and it moves to the next episode on its own. One button hands the frame to the browser's own controls, which adds playback speed and picture-in-picture.

Subtitles

Some voiceovers come with WebVTT subtitle tracks. Those are attached to the player, so the browser lists them by language and starts the one the site marks as default. Most tracks have none — the original-audio one usually does.

Downloading a series

Pick a season and episode and it works through to the end of the show, one file at a time, carrying on into the next season. Failures are retried and then skipped rather than stopping the run, and progress is saved after every episode.

English

Genres, countries, table headings and voiceover types come from a list built into the script. Titles use the original-language name the site already stores, so shows get their real English title rather than a translation of the Russian one.

Connection

While something is playing it shows how many seconds are buffered and how quickly the file is arriving, which is usually enough to tell whether the quality you picked is going to hold.

If the site changes

Everything is read from the URL, meta tags and data attributes before any CSS class name, because those are the parts the site is least likely to change. A restyle on their end shouldn't break it.

Install

01

Get a script manager

Tampermonkey or Violentmonkey. Tampermonkey is recommended — the download queue and subtitles need its APIs.

02

Open the script

rezka-downloader.user.js — your extension will offer to install it.

03

Open any title

The new interface takes over before the page paints. Original site in the header hands the old one back at any time.

Worth knowing

It's a single file with no build step. There's a test suite that runs the real script against saved copies of the site's pages, and a script that loads it into the live site and checks the interface actually works before each release.

Two limits. Each voiceover is a separate file rather than several audio tracks in one, so there's no way for any player to offer an audio-track menu — the Voice picker is how you switch. And a few releases are served only as HLS, which a plain video element can't play; those fall back to the site's own player instead of showing a dead frame.
