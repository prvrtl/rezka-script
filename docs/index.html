What it does

player

Plays the file, not the page

A real <video> on the direct link — no Premium banner, no player chrome you didn't ask for. Keyboard control, resume per episode, and autoplay into the next one.

native mode

Or hand it to the browser

One button switches to the browser's own controls, bringing subtitles, playback speed, picture-in-picture and cast. Subtitle tracks come from the site's own WebVTT files, listed by language.

queue

A whole show, unattended

Pick a season and episode; it downloads to the end of the series, one at a time, rolling into the next season. Retries on failure, never stops on one, and saves progress after every episode.

english

Readable, without a round trip

The interface is English. Titles use the site's own original-language name; genres, countries and voiceover types come from a built-in glossary. Nothing is sent anywhere to translate.

throughput

Know before it stalls

A live readout of seconds buffered, fill rate and — where the size is readable — throughput and file size. Buffer depth is what predicts a stall, so a paced CDN isn't misreported as failing.

durability

Survives a redesign

Everything is read from the URL, og: tags, microdata and data- attributes before any class name. A test runs the whole UI against a page with every structural class renamed.

Install

01

Get a script manager

Tampermonkey or Violentmonkey. Tampermonkey is recommended — the download queue and subtitles need its APIs.

02

Open the script

rezka-downloader.user.js — your extension will offer to install it.

03

Open any title

The new interface takes over before the page paints. Original site in the header hands the old one back at any time.
